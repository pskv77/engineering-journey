# Courses

This directory tracks external courses used as supporting resources in the engineering roadmap.

Courses are not the roadmap itself.

They are selected when they help achieve a specific learning goal defined by the roadmap or current sprint.

## Core principle

The learning process is skill-driven, not course-driven.

The order is:

    roadmap goal
        ↓
    required skill
        ↓
    selected learning resources
        ↓
    hands-on practice
        ↓
    project integration
        ↓
    assessment

A course may support this process, but completing a course does not automatically mean that the corresponding skill has been acquired.

## Possible sources

Courses may include materials from:

- Yandex Practicum;
- ITMO;
- vendor academies;
- other universities;
- technical learning platforms;
- professional training programs.

## Course tracking

For each significant course, record:

- course name;
- source;
- status;
- start and completion dates;
- modules completed;
- useful concepts;
- concepts already known;
- practical tasks;
- artifacts added to Git;
- skills affected;
- rank before;
- rank after assessment;
- final evaluation of usefulness.

## Evidence

Whenever possible, knowledge obtained from a course should be transferred into:

- labs;
- projects;
- scripts;
- configurations;
- documentation;
- assessments.

Course progress alone is not considered sufficient evidence of practical capability.

## Integration with sprints

Courses should normally be attached to an active sprint or roadmap goal.

Example:

    Sprint goal: Linux processes and services
        ↓
    Relevant external Linux module
        ↓
    Our own Linux labs
        ↓
    Integration into project
        ↓
    Sprint assessment

This prevents the learning system from becoming a collection of unrelated courses.
