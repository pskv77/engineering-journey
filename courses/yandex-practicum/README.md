# Yandex Practicum

This directory tracks Yandex Practicum courses and modules used within the engineering roadmap.

Yandex Practicum is treated as an additional learning resource rather than the foundation of the roadmap.

## Role in the learning system

Practicum may provide:

- structured explanations;
- exercises;
- alternative explanations of difficult concepts;
- practical assignments;
- additional repetition;
- external feedback where available.

The roadmap determines when a Practicum course is useful.

The existence of a course does not determine what should be learned next.

## Course progress

Each course or significant module may have its own directory and README.

Recommended information:

- course name;
- URL;
- status;
- modules;
- progress;
- notes;
- useful concepts;
- practical tasks;
- Git artifacts;
- relationship to the current sprint;
- final assessment.

## Recommended status values

- Planned
- In Progress
- Completed
- Paused
- Not Relevant

## Learning evidence

When possible, course exercises should lead to independent work in this repository.

Examples:

- rewrite an exercise without looking at the original solution;
- create an additional lab;
- integrate the concept into the main project;
- troubleshoot an intentionally broken version;
- explain the mechanism in personal notes.

## Important principle

Course completion and skill rank are separate metrics.

A course may be 100% complete while the corresponding practical skill remains weak.

Skill ranks are changed only after independent evidence and assessment.
