# Roadmap

This directory contains the structure and logic of my long-term engineering learning path.

The roadmap defines:

- what should be learned;
- in what order;
- why this order was chosen;
- which skills depend on other skills;
- which areas are foundations, expansions or specializations;
- how learning phases and sprints are connected.

## Main principle

The roadmap is not built around individual courses.

Courses, books, labs and other materials are supporting resources.

The roadmap is built around engineering skills and practical capability.

## Learning architecture

The learning process is organized around three parallel tracks:

### Foundation

Core technical knowledge required for further engineering work.

Examples:

- Computer Science
- Python
- Linux
- Bash
- SQL
- networking fundamentals

### Engineering

Practical infrastructure and delivery skills.

Examples:

- Git
- APIs
- Docker
- Nginx
- CI/CD
- monitoring
- Infrastructure as Code
- Kubernetes
- cloud platforms

### Security

Security is not treated as a separate final layer.

Security practices are integrated into every technical area:

- Linux hardening
- network segmentation
- IAM
- secure coding
- secrets management
- container security
- CI/CD security
- Kubernetes security
- cloud security
- monitoring and incident response

## Learning phases

The roadmap is divided into large phases.

Each phase contains several two-week learning sprints.

The current initial direction is:

Phase I — Engineering Foundation

Phase II — Infrastructure Engineering

Phase III — Modern Infrastructure and Cloud

Phase IV — Security Specialization

These phases may change as skills, interests and professional goals evolve.

## Important principle

The roadmap is a living document.

It may be updated after:

- sprint assessments;
- comprehensive control exams;
- new work experience;
- university coursework;
- practical projects;
- changes in professional goals.

Changes should be recorded through Git instead of silently replacing previous planning decisions.
