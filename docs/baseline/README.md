# Baseline

This directory contains snapshots of my engineering skill level at different stages of the learning roadmap.

The baseline is used to answer three questions:

1. What can I do independently right now?
2. What knowledge needs to be restored or systematized?
3. What technologies have not yet been properly learned or practiced?

## Current baseline

The initial baseline was created after Assessment Week in August 2026.

Main document:

- `baseline-v1.md` — starting point before the structured learning program.

## Source data

The baseline is based on diagnostic exams covering:

- Computer Science Fundamentals
- Programming & Automation
- Linux & Systems
- Networks & Network Security
- Windows & Enterprise Infrastructure
- Cybersecurity Engineering
- DevOps, Cloud & Infrastructure Security

Detailed exam files, spreadsheets and review materials are stored separately in the `assessments/` directory.

## Versioning

Baseline documents are never overwritten.

Future assessments should create new versions, for example:

- `baseline-v1.md`
- `baseline-v2.md`
- `baseline-v3.md`

This makes it possible to compare skill development through Git history and explicit baseline snapshots.

## Important principle

A low rank can mean different things:

- previously studied but forgotten;
- understood conceptually but not practiced;
- fragmented knowledge that needs systematization;
- a genuinely new technology that has never been learned.

These cases should not be treated the same way when planning future learning.
